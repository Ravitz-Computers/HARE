Hardware Adaptive RGB Engine (HARE)

HARE is an open-source project built to make controlling and customizing RGB hardware simple, flexible, and actually fun.

It uses OpenRGB, and other open-source software as well as various SDK's and API's behind the scenes to handle the hardware side of things, while HARE focuses on making the experience easier to use
and giving you plenty of room to customize things exactly how you want.

This project was created with help from Claude and has been a fun learning experience along the way. I’m sure there are things I could have done better, and probably a few things I did completely wrong—but that’s part
of the fun of building something from scratch.

Feel free to explore the project, try it out, break it, improve it, or just enjoy it. Contributions and feedback are always welcome, and I promise not to sell out with this program unless they offer me ALOT of money.

Thanks for checking out HARE! 🐰🌈
